OSDU Schema Visualizer & Data Model Explorer

Interactive explorer and visual graph for OSDU JSON Schemas and OSDU Data Definitions. Search, browse, and inspect entity relationships across 1,400+ schemas including Master Data, Work Product Components (WPC), Reference Data, and Abstract Schemas from The Open Group OSDU Forum.

Explore OSDU Schema Categories

  • Master Data Schemas: Well, Wellbore, SeismicAcquisitionSurvey, Rig, Field, Organisation, Basin, Prospect, StorageFacility, and more.
  • Work Product Component (WPC) Schemas: WellLog, WellboreTrajectory, WellboreMarkerSet, SeismicTraceData, SeismicInterpretationSet, Document, and Activity.
  • Reference Data Schemas: UnitOfMeasure, WellStatus, ActivityCode, AliasNameType, VerticalMeasurementType, and lookup taxonomies.
  • Abstract & Manifest Schemas: AbstractCommonResources, AbstractSpatialLocation, AbstractLegalTags, GenericMasterData, and GenericDataset.

Key Features

  • Interactive Entity-Relationship Graph (ERD) powered by React Flow and Dagre.
  • Instant type-ahead search by schema name, $id, or version.
  • Deep property inspection, inheritance chain visualization, and reference data resolution.
  • Offline support and local custom schema folder analysis.
