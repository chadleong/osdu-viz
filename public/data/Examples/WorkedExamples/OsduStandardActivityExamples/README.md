# OSDU Standard Records - Activity Template Worked Examples

The OSDU Forum has developed standardised Activity Templates for common industry workflows and processes within the OSDU Data Platform. These templates are stored in the [OsduStandardRecords/ActivityTemplates](../../../OsduStandardRecords/ActivityTemplates) folder, organised by the OSDU Domain classification using the `<Level 1>`**.**`<Level 2>` hierarchy as outlined [here](../../../E-R/Domains.md).

Accompanying **WorkedExample** records for these Activity Templates can be found in this folder, following the same OSDU Domain classification. Below is a summary list of currently available Activity Templates and their accompanying WorkedExamples.
