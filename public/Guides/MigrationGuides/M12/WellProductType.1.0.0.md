# Migration from MaterialType to `osdu:wks:reference-data--WellProductType:1.0.0`

The schema [`osdu:wks:reference-data--WellProductType:1.0.0`](../../../E-R/reference-data/WellProductType.1.0.0.md)
supersedes MaterialType for Wellbore's property `PrimaryMaterialTypeID`, which is deprecated from Wellbore:1.1.0
onwards. Instead, the potentially more precise WellProductType is used for the new property `PrimaryProductTypeID`.
