4. **Well**
    1. Added [osdu:wks:master-data--Well:1.5.0](../E-R/master-data/Well.1.5.0.md), introducing `data.WellReferencePoint` — the Well Reference Point (WRP), a permanent, recoverable, fixed point of deepest horizontal constraint typically used as the tie-in point for a well's first survey and plan (commonly its position at seabed or ground level). Carries the WRP's type (e.g. Vertical, Slant Rig, Curved Conductor), its TVD/MD relative to the well's default vertical measurement, inclination/azimuth, and northing/easting/offset coordinates. See [migration guide](../Guides/MigrationGuides/M27.1/master-data--Well.1.4.0.md).
    2. Added [osdu:wks:master-data--Risk:2.0.0](../E-R/master-data/Risk.2.0.0.md) — **BREAKING CHANGE**: removed `data.Preventions[]`; prevention and mitigation actions are now both recorded in `data.Mitigations[]`, which is now indexed as `nested`. `data.WellboreID` is no longer required, so a Risk need not be tied to a planned Wellbore. See [migration guide](../Guides/MigrationGuides/M27.1/master-data--Risk.1.2.0.md).
