5. **Rig**
    1. Added eleven new rig-equipment master-data types, tracked by `EquipmentInventory` alongside the existing `RigDerrick`/`RigPump`/`RigRiser`: [RigAnchor](../E-R/master-data/RigAnchor.1.0.0.md), [RigBoiler](../E-R/master-data/RigBoiler.1.0.0.md), [RigCementUnit](../E-R/master-data/RigCementUnit.1.0.0.md), [RigCentrifuge](../E-R/master-data/RigCentrifuge.1.0.0.md), [RigCoilTubingReel](../E-R/master-data/RigCoilTubingReel.1.0.0.md), [RigCrane](../E-R/master-data/RigCrane.1.0.0.md), [RigDegasser](../E-R/master-data/RigDegasser.1.0.0.md), [RigHydrocyclone](../E-R/master-data/RigHydrocyclone.1.0.0.md), [RigMotor](../E-R/master-data/RigMotor.1.0.0.md), [RigPit](../E-R/master-data/RigPit.1.0.0.md), and [RigShaker](../E-R/master-data/RigShaker.1.0.0.md). Each defines a small set of physical/rated properties for that equipment type plus the shared `AbstractUnitEquipment` fragment. All are now introduced with a full example record in the [Rig Worked Example](../Examples/WorkedExamples/Rig/README.md).
    2. Added [osdu:wks:master-data--EquipmentInventory:1.1.0](../E-R/master-data/EquipmentInventory.1.1.0.md) — `1.0.0`'s `EquipmentID` relationship only allowed a reference to `RigDerrick` or `RigPump`; `1.1.0` widens it to also cover the eleven new equipment types above (plus `RigRiser`), so EquipmentInventory can actually track them.
    3. Bumped [osdu:wks:master-data--RigPump:1.1.0](../E-R/master-data/RigPump.1.1.0.md) alongside the equipment work above. Like the eleven new types, it now also carries the shared `AbstractUnitEquipment` fragment. See [migration guide](../Guides/MigrationGuides/M27.1/master-data--RigPump.1.0.0.md).
    4. Added [osdu:wks:master-data--RigHydrocyclone:1.0.0](../E-R/master-data/RigHydrocyclone.1.0.0.md)'s with five equipment-specific properties (`IsMudCleaner`, `FlowCapacity`, `AmountOfCones`, `ConeType`, `ConeSize`)
    5. Updated [Rig Worked Example](../Examples/WorkedExamples/Rig/README.md) with the new additions, and documented `RigSurfaceEquipment` as a planned-but-not-yet-published object.
    6. Added [osdu:wks:reference-data--CoilTubingWrapType:1.0.0](../E-R/reference-data/CoilTubingWrapType.1.0.0.md) (OPEN governance), used by `RigCoilTubingReel` — 4 reference values describing how tubing is spooled onto the reel: `LevelWind`, `Random`, `FigureEight`, and `Helical`.
