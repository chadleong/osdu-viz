Reading the numbers above "New Schemas" (11) counts 3 headline records (NotionalSeismicProcessingProduct, WellboreHoldUpDepth, CasingComponentCatalog) plus 8 supporting reference-data lists introduced to back them (§2–§4). "New Reference Values" (20) counts populated values across 7 of those 8 new lists — CatalogMaterialGrade ships this milestone as an empty list, ready for future population, so it isn't counted here. A further 10 reference values were added to three existing lists this milestone (Sample Analysis Family/SubFamily/Type, §2) — additive content to schemas whose own version number didn't change, so it's tracked separately from "New Reference Values" rather than folded into it. Neither figure includes the Geomatics work (§1): OGC WKT2 support is a 2,900-record property addition to two existing schemas, not new reference values in the code-list sense — see below. "Migration Guides" (12) covers the 5 version upgrades above plus reference-data "wiring" updates that route the upgrades automatically; new schemas have nothing to migrate from. No breaking changes or security fixes shipped this milestone.

At a glance — everything below is already approved and shipped
  • New capability OSDU's CoordinateReferenceSystem and CoordinateTransformation schemas gain OGC WKT2 support, improving interoperability with modern open-source geospatial tooling (PROJ, GDAL, Apache SIS) and aligning with ISO 19111:2019 — populated across 2,900 existing records (2,547 CRS + 353 CT). (§1)
  • New capability WellboreHoldUpDepth captures a depth or interval where casing/tubing damage blocks tool passage to the designed drift diameter. (§3)
  • New capability CasingComponentCatalog provides a standardized, vendor-spanning catalog for casing products, enabling as-installed components to trace back to their product specification. (§3)
  • New capability NotionalSeismicProcessingProduct groups the seismic trace data belonging to a single logical processing deliverable; SeismicTraceData gains the link to it and deprecates TimeLapse in favour of the more general TimeLapseAssociations. (§2)
  • Process change ConnectedSourceDataJob can now preserve specific attribute paths across updates (PreserveOnUpdate) and gains a configurable email notification policy (Always / On Error / Never) for job runs. (§4)
  • New capability ConnectedSourceRegistryEntry gains Email API integration for ingestion-run notifications, with a configurable report period and a reusable JSON payload template. (§4)
  • Reference data delivered Sample Analysis Family, SubFamily, and Type reference lists extended with fluid-sensitivity test types — Roller Oven Test, Capillary Suction Time, Proppant Embedment, Pressure Dependent Permeability, and Pore Scale Modelling. (§2)
  • Everything else No breaking changes and no security fixes this milestone — every change above is purely additive.
1

Geomatics

Coordinate Reference Systems

Coordinate reference system and transformation schemas gain OGC WKT2 (Well-Known Text 2) support, complementing the existing ESRI WKT1 format.

Largest-scale change this milestone — OGC WKT2 population 2,900 existing records populated with the new OGCWellKnownText2 property — 2,547 across CoordinateReferenceSystem, 353 across CoordinateTransformation. This is a property added to existing records, not new reference-data entries, so it's counted here rather than in the "New Reference Values" figure above.
RecordChangeWhat it does
CoordinateReferenceSystem1.1.0→1.2.0Adds OGCWellKnownText2 property; populated across 2,547 records.
CoordinateTransformation1.1.0→1.2.0Adds OGCWellKnownText2 property; populated across 353 records.
Technical detail — WKT2 tooling

EpsgManifestGenerator.py — fetches OGC WKT2 from the EPSG GeoRepository for all CRS and coordinate transformations; adds lifecycle support for deprecated records and an InactiveIndicator property to filter them; adds alias handling for comma-separated naming systems (EPSG, OGP, etc.); merge summary reporting now separates horizontal vs. vertical transformations.

EsriWktDynamicGenerator.py — adds an OGC WKT2 caching mechanism and retrieval methods for dynamic generation scenarios.

GeoRepository integration — dynamic token refresh for uninterrupted API access; enhanced credential handling for authenticated queries.

Python dataclasses — CoordinateReferenceSystem.py and CoordinateTransformation.py regenerated from the 1.2.0 self-contained schemas via QuickType; fixed AbstractAliasNames property mapping (alias_name_type_id); added revision_date timezone safety for ISO 8601 compliance; hardened GeoJSON feature-collection serialization.

Worked examples — OGCWellKnownText2 populated across 12 CRS/CT worked examples, validated against the current 1.2.0 manifests by EPSG code matching.

Subsurface

Geology & Petrophysics · Geophysics

Fluid-sensitivity test types added to the Sample Analysis reference data, and a Geophysics update consolidating seismic trace data lineage under a shared processing-product concept.

Code listValues addedBacks

SampleAnalysisSubFamily5Roller Oven Test, Capillary Suction Time, Proppant Embedment, Pressure Dependent Permeability, Pore Scale Modelling

Technical detail — Geology & Petrophysics

None of the three lists above changed schema version (all remain 1.0.0) — this is reference-value content added to existing, unchanged list definitions, not a schema upgrade. Pore Scale Modelling: starting from scans or photography (e.g. CT) of physical samples, digital rock models can be created and run to measure properties digitally; other measured data can be used to calibrate the model.

RecordChangeWhat it does
SeismicTraceData1.5.1→1.6.0Deprecates TimeLapse in favour of the new TimeLapseAssociations; adds NotionalSeismicProcessingProductID and IsPreStack.
NotionalSeismicProcessingProductNewThe set of seismic trace data comprising a single logical seismic processing deliverable.
Technical detail — Geophysics

SeismicTraceData 1.6.0 — new TimeLapseAssociations attribute links to one or more time-series work-product-components via AbstractTimeSeriesLink (existing), defining the relationship between a representation and the time series holding its full list of time steps. New NotionalSeismicProcessingProductID bundles trace data sets sharing the same processing output. New IsPreStack flags volumes that haven't been stacked.

Also added: a Velocity worked example record and documentation.

Two new record types — one for depth intervals where casing damage blocks tool passage, one a vendor-spanning casing product catalog — each with their own supporting reference data.

WellboreHoldUpDepth 1.0.0 — backed by three new reference lists: DepthMeasurementType, HoldUpDepthType, HoldUpDepthCategory.

CasingComponentCatalog 1.0.0 — backed by three new supporting reference-data schemas: CatalogMaterialGrade (LOCAL governance, OSDU; no values populated yet), MaterialGradeStandardType, and DriftType.

External Data Sources

EDS Notifications

Both External Data Sources record types gain notification capability — configurable email alerts on job outcomes, and API-driven ingestion-run reports.

RecordChangeWhat it does
ConnectedSourceDataJob1.7.0→1.8.0Adds PreserveOnUpdate (attribute paths to keep unchanged across updates) and an email notification policy.
EdsNotificationPolicyNewFIXED reference list of 3 values — Always, On Error, Never.

PayloadTemplateNewReference list of 1 value; lets a Data Provider/Operator define the JSON payload template for their Email API.
Technical detail

ConnectedSourceDataJob 1.8.0 — if the FailedRecords array is populated, PreserveOnUpdate determines whether those paths are retried on the next run or left unchanged. EdsNotificationPolicy (FIXED) sets the email preference for job-run notifications.

ConnectedSourceRegistryEntry 1.5.0 — new EmailApiSchemes section enables Email API integration; ReportPeriod added to the SmtpSchemes section specifies how many days an emailed report covers; the new PayloadTemplate reference data lets the Data Provider/Operator tailor the JSON payload to the Email API they call.
